# 声控逃亡

更新时间：2026-08-13
项目状态：首个正式游戏，方案梳理中
工作名：声控逃亡（暂定，正式名称尚未确定）
首发平台：抖音小游戏

## 一句话定义

一款竖屏第三人称自动跑酷游戏：玩家用相对高音触发跳跃、用相对低音触发翻滚，在追捕压力下连续通过障碍，最终只按逃亡距离竞争。

## 立项目标

本项目的首要目标不是稳定收益，而是在最多 14 天的首轮实验中跑通并记录一条完整链路：

玩法假设
→ 音频技术验证
→ 可玩原型
→ 抖音小游戏适配
→ 短视频素材
→ 真实用户漏斗
→ 留存与分享验证
→ 继续、转型或停止决策

无论项目最终是否继续，都必须沉淀可复用的声音输入模块、小游戏平台适配层、埋点体系、素材实验方法和复盘模板。

## 已锁定决策

除非技术验证证明不可行，以下内容不在当前阶段反复改动：

- 第一个正式游戏项目。
- 抖音小游戏优先，不同时开发微信版本。
- 9:16 竖屏、第三人称视角、角色自动向前奔跑。
- 高音触发跳跃，低音触发翻滚，中音或静音保持奔跑。
- 高低音按玩家个人音域判断，不使用统一绝对频率。
- 跳跃用于地面墙体，翻滚用于底部留有通道的悬空墙体。
- 对外唯一主成绩是逃亡距离；连击等反馈不能替代距离成为第二套主分数。
- 原始声音默认只在本地实时分析，不保存、不上传。
- P0 不识别具体词语，不接入实时大模型。
## 待验证假设

- 高低音在不同玩家、设备和普通室内环境中能够稳定区分。
- 用户愿意授权麦克风并在真实场景中发声。
- 声控带来的重玩和分享明显优于等价触控操作。
- 两种动作可以通过节奏组合支撑至少 3 分钟的连续挑战。
- 追捕距离容错能降低误识别挫败感，同时保留紧张感。
- 距离纪录和同图挑战足以驱动重玩、分享或次日回访。
## 当前范围

首轮只完成音频技术 Spike 和 P0 可玩版本。商城、养成、多角色、三赛道、复杂剧情、实时多人和具体语音识别均不进入当前范围。
