# 声控逃亡：玩法规格 v0.1

更新时间：2026-08-13
状态：讨论基线，所有数值均为首轮测试初值

## 1. 产品体验

### 1.1 核心体验

玩家不是在唱歌，也不是持续喊叫，而是在高速追逐中用两个短促、容易重复的音高动作完成一串"声音反应乐句"。

自动奔跑
→ 看清障碍
→ 高音跳 / 低音滚
→ 成功通过或碰撞失速
→ 追捕者接近
→ 继续挑战更快的节奏
→ 被追上后结算距离

### 1.2 一局时长

- 新玩家目标：30–60 秒
- 熟练玩家目标：60–120 秒
- 单次会话目标：连续游玩至少三局
无限模式是产品形式，不代表普通玩家需要持续发声数分钟。

## 2. 首次进入流程

启动
→ 点击"开始逃亡"
→ 一屏说明麦克风用途
→ 用户主动授权
→ 采集环境噪声
→ 校准舒适低音和高音
→ 各完成一次跳跃与翻滚练习
→ 3、2、1 开跑
→ 被捕
→ 距离结算与立即重玩

产品目标：校准过程中 10 秒内给出第一次角色动作反馈，完整校准中位时间最终压到 30 秒内。技术 Spike 首先保证可靠性，不为了缩短流程减少必要样本。

第二局默认复用本地模板。检测到设备、环境或音域明显变化时，才提示快速重校。

## 3. 控制规则

|||
|---|---|
|稳定高音|触发一次跳跃|
|稳定低音|触发一次翻滚|
|中性音、静音或无法确认的声音|保持自动奔跑，不触发动作|


基础约束：

- 每段持续声音最多触发一个动作。
- 必须回到中性音或静音后，才能触发下一动作。
- 从高音直接滑到低音不能连续触发两次。
- 空中或翻滚中收到另一指令时直接忽略，不排队。
- 翻滚时长固定，不随低音持续时间变化。
- 模糊输入宁可不响应，也不能把高音误判成低音。
屏幕常驻一条克制的音高反馈条，显示当前处于低、中、高或无效状态。它用于建立玩家对系统的信任，不承担装饰作用。

## 4. 角色状态

RUN
├→ JUMP → RUN
├→ ROLL → RUN
├→ STUMBLE → RECOVER → RUN
└→ CAUGHT

首轮动作参数：

|||
|---|---|
|跳跃总时长|900ms|
|跳跃有效避障区间|动作开始后 180–720ms|
|翻滚总时长|760ms|
|翻滚有效避障区间|动作开始后 100–620ms|
|碰撞踉跄|650ms|
|碰撞后保护|1.2s|


这些参数必须结合端到端识别延迟和真机手感调整。

## 5. 障碍规则

P0 只有两种动作障碍：

||||
|---|---|---|
|H|从地面向上生长、角色可以越过的矮墙或断面|高音跳跃|
|L|与上方结构连接、底部明显留有通道的悬空横墙|低音翻滚|


"完整墙"和"半墙"只作为原始概念，不作为最终玩家文案。两类障碍必须依靠轮廓、连接方向、地面空隙和阴影区分，不能只靠颜色。

障碍到达角色位置记为 T=0：

- 首轮动作接受窗口：T=-700ms 至 T=-250ms
- 首轮完美反馈窗口：T=-520ms 至 T=-380ms
- 错误动作本身不扣分，实际碰撞才产生处罚
- 初期障碍最小间隔：1.1s
- 后期最低间隔暂不小于：0.82s
完美反馈只影响追捕容错和演出，不在结算页形成另一套主成绩。

## 6. 追捕与容错

声控存在天然延迟和设备差异，一次碰撞不立即结束。内部使用 lead 表示与追捕者的领先距离：

|||
|---|---|
|开局|70/100|
|普通通过|0|
|完美通过|+2，暂定上限 80|
|碰撞|-28|
|降至 0|被追上，结束本局|


碰撞后角色速度降至正常速度的约 35%，持续 650ms。首轮目标是允许新玩家承受两次明显失误，第三次附近结束。

为了避免熟练玩家无限持续：

- 0–30 秒：不自然衰减
- 30–60 秒：每秒暂减 0.25
- 60–90 秒：每秒暂减 0.5
- 90 秒后：每秒暂减 0.8
是否保留自然衰减，需要由高手实测决定。不能为了控制局长制造无反馈的突然追近。

## 7. 速度与距离

- 初始世界速度：约 6m/s
- 20 秒后逐步加速：暂定每秒增加 0.06m/s
- 最大速度：暂定 12.5m/s
- 碰撞失速会自然减少单位时间里程，不额外扣除显示分数
distance = 对角色实时世界速度随时间积分

对外显示整数米，内部保留更高精度。排行榜和分享只强调距离；如必须处理完全相同距离，使用未取整距离和记录时间作为后台排序依据。

每日挑战必须使用同一障碍序列。随机练习成绩不与每日同图成绩混排，触控降级成绩也不与声控成绩混排。

## 8. 节奏片段

不做完全随机生成，而是从经过测试的节奏片段拼接：

教学：H - -   L - -
基础：H - H   L - L   H - L   L - H
进阶：H H -   L L -   H L -   L H -
乐句：H L H -   L H L -   H H L -   L L H -

首轮节奏：

- 0–15 秒：每拍约 1.40s，只使用教学与基础片段
- 15–35 秒：每拍约 1.15s，加入进阶片段
- 35–60 秒：每拍约 0.95s，加入三动作乐句
- 60 秒后：逐步逼近 0.85s
拼接约束：

- 连续动作最多三个，之后至少一个空拍。
- 同一片段不连续出现超过两次。
- 新乐句首次出现前留出一个空拍。
- 碰撞恢复期不生成理论上无法通过的障碍。
- 每局前 10 秒固定，避免新手体验受随机数支配。
## 9. 镜头与信息层级

目标画幅为 9:16：

- 角色脚底位于屏幕高度约 78%。
- 消失点位于屏幕高度约 30%–34%。
- 角色高度约占屏幕 12%–15%。
- 障碍至少在碰撞前 1.35s达到可辨识尺寸。
- 常态镜头保持稳定；碰撞时只做约 120ms的轻微震动。
- 追捕者最多占屏幕底部约 12%，不能遮挡赛道和输入反馈。
高音反馈向上运动，低音反馈向下压缩，利用天然方向映射。背景装饰不得出现与两类障碍相似的轮廓。

## 10. 结算与分享

结算页第一视觉只显示：

本次逃亡：486 米
个人最好：512 米

次级信息可以显示本局碰撞次数和高低音识别概况，用于帮助玩家理解失败，但不做复合总分。

P1 自动回放最后 6–8 秒，叠加音高轨迹、动作图标、追捕距离和最终米数。原始玩家声音默认不进入分享内容；只有用户明确确认后才能携带。

## 11. P0 与 P1

### P0：验证玩法成立

- 竖屏第三人称自动跑
- 麦克风授权、噪声采样和个人音域校准
- 高音跳跃、低音翻滚
- 两类障碍和约 14 个节奏片段
- 追捕距离、碰撞容错和随时间加速
- 距离结算与本地最佳
- 教学、重开、暂停和切后台恢复
- 核心埋点
- 同一种子分享入口
### P1：P0 数据成立后

- 每日同图挑战
- 好友成绩线
- 最后 6–8 秒无原始人声回放
- 分享视频叠加音高轨迹
- 自动环境漂移修正
- 小声模式
- 一种新的节奏机关
- 触控兼容与对照模式
### 明确不做

- 商城和皮肤养成
- 签到、任务和赛季
- 多角色、多赛道和道具系统
- 复杂剧情
- 具体词汇识别
- 实时多人竞技
- 与奖金关联的严肃排行榜
