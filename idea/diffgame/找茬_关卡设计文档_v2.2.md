## 设计哲学

### 一句话设计宣言

每关都是一句话，三关构成一个段落，每一天的挑战是一篇完整的教学文章。

玩家离开时不应该只记住"我今天差一点就过了"，而应该记住"我今天学会了一个找茬的方法"。

### 核心原则

- 教→练→考：三关不是三个独立关卡，而是三个递进的认知阶段
- 每一次失败都有原因可寻：玩家失败时，能明确说出"我忽略了XX类型的差异"
- 复杂度从场景中来，不从欺骗中来：不作伪差异陷阱，难度来自真实的视觉搜索复杂性
- 空间节奏：每一关内部有"张→弛→张"的节奏，不是全程高压
## Level: 每日挑战 — 完整关卡系统

### Intent

Player Fantasy：一个眼力越来越敏锐的观察者。
                从新手变成专家只需要三关，
                每天都能感受到自己比昨天更会"看"。

Pacing Arc：  Coach阶段(信心建立)
           → Challenge阶段(技能验证)
           → Mastery阶段(极限挑战+心流体验)

New Mechanic Introduced：
  第1关 引入 "差异类型体系" —— 颜色、缺失、位移、大小、纹理 五大类型
  第2关 引入 "分层扫描法" —— 从上到下、从左到右的系统性搜索策略
  第3关 引入 "时间管理" —— 何时使用提示道具、何时跳过可疑区域

Narrative Beat：
  三关共享一个主题世界的不同时间/视角。
  玩家在同一个"世界"里观察不同深度的细节。

## 关卡详细设计

### 第1关：Coach — "颜色和缺失"

╔═══════════════════════════════════════════════════════╗
║ 关卡ID: daily_YYYYMMDD_01_coach                      ║
║ 通过率目标: > 90%（不是"闭眼过"，而是"学会后过"）       ║
║ 时间限制: 90 秒                                       ║
║ 差异数量: 5 处                                       ║
║                                                     ║
║ 教学重点: 高对比度区域的「颜色改变」和「物体缺失」       ║
╚═══════════════════════════════════════════════════════╝

#### 场景规范

主题统一性：与当天的第2、3关属于同一主题世界。

例：如果今天主题是"厨房"，第1关是整洁明亮的厨房，道具清晰可辨；第2关是烹饪中的厨房，多了烟雾和水渍遮挡；第3关是宴会后的厨房，堆满锅碗瓢盆，视觉噪音极大。

||||
|---|---|---|
|场景复杂度|简约背景 + 少量前景物体|确保所有差异都在用户的"第一眼视线范围"内|
|颜色对比度|主体与背景对比度 > 60%|不需要仔细分辨就能发现颜色不同的物体|
|物体数量|8-12 个离散物体|物体少 → 用户可以逐个检查 → 建立"逐个排查"的习惯|
|差异分布|全部位于前景区域|用户不需要深入背景寻找|
|差异类型|3 个颜色改变 + 2 个物体缺失|教授最基本的两种差异类型|


#### 差异设计（5处，按"一眼可见度"排序）

||||||
|---|---|---|---|---|
|1|颜色改变|画面正中央的物体|⭐⭐⭐⭐⭐|"哦，这个游戏就是找不一样的"|
|2|物体缺失|前景左侧独立物体|⭐⭐⭐⭐|"不仅是颜色，还有东西会消失"|
|3|颜色改变|右侧显眼位置|⭐⭐⭐⭐|强化颜色类型的识别|
|4|物体缺失|中景台面边缘|⭐⭐⭐|"开始需要注意边缘区域了"|
|5|颜色改变|两个相似物体之一(对比法)|⭐⭐⭐|教用户"对比法"：两个长相相似的东西，一个变了颜色|


#### 空间节奏 — Coach阶段的情绪曲线

时间轴   0s─────────15s──────────45s──────────75s───────90s
         │          │            │            │          │
发现差异  ████  (找到2个)  ████ (找到1个)  ██ (找2个)   █ (结算)
         │          │            │            │          │
情绪    兴奋      自信         满意        小小的得意    "通关！"
         "这也太  "轻轻松松"   "需要看一   "找到了！"
         简单了吧"            下边上"

关键设计点：90秒的时间对5处差异来说极其充裕，但差异的分布不是均匀的。前15秒内用户能看到至少2处明显差异 → 立刻建立信心。中间30秒是一个"平稳期"，用户开始有意识地搜寻边缘。最后20秒找到最后1-2处 → 制造"刚好找到"的轻微紧张感，为第2关的心理过渡做准备。

#### 教学埋点

第1关结束后，结算页面展示一个简短的视觉提示：

┌──────────────────────────┐
│   ✅ 通关！               │
│                          │
│   🎯 你发现的所有差异都是： │
│   🔴 颜色改变 (3处)      │
│   ❌ 物体缺失 (2处)      │
│                          │
│   💡 小提示：找茬时，      │
│   先注意颜色不同的物体     │
│   和完全消失的物体         │
│                          │
│      [ 进入第2关 ]        │
└──────────────────────────┘

目的：让玩家无意识地"学到"差异分类。明天他面对全新的第1关时，潜意识里已经会分类搜索了。

### 第2关：Challenge — "位移、大小和纹理"

╔═══════════════════════════════════════════════════════╗
║ 关卡ID: daily_YYYYMMDD_02_challenge                  ║
║ 通过率目标: 25-35%                                    ║
║ 时间限制: 75 秒                                       ║
║ 差异数量: 7 处                                       ║
║                                                     ║
║ 教学重点: 需要用「分层扫描法」找到的                 ║
║          「位移」「大小变化」「纹理差异」             ║
╚═════════════════════════════════════════════════════╝

#### 场景规范

递增复杂度：同一个主题世界，但是"动态中的场景"。

继续"厨房"案例：第2关是一个正在烹饪中的厨房。灶台上有锅、油烟升起、厨具散落。比第1关多了"动作感"和"遮挡关系"。

||||
|---|---|---|
|场景复杂度|中等写实 + 动态元素（烟雾、水花、光影）|增加视觉干扰，但所有干扰都是"有意义的场景元素"|
|颜色对比度|主体与背景 30%-50%|不能靠扫一眼看出来了|
|物体数量|15-25 个物体，存在遮挡关系|用户需要一个一个排查 → 被迫使用"分层扫描法"|
|差异分布|6处中景 + 1处浅背景|用户必须把视线从前景移开|
|差异类型|2位移 + 2大小 + 2纹理 + 1难度奖励|引入第1关没出现过的新类型|


#### 差异设计（7处，按"需要用到的搜索策略"排序）

||||||
|---|---|---|---|---|
|1|大小变化|低|扫一眼|延续第1关的信心："熟悉的套路"|
|2|位移|低|扫一眼|引入新类型，但放在显眼位置|
|3|纹理差异|中|对比法|引入"表面纹理不同"概念|
|4|大小变化|中|需要对比附近的同类物体|大小变化如果孤立存在很难发现|
|5|位移|中高|分层扫描|物体被部分遮挡，位置偏移不明显|
|6|纹理差异|高|逐层排查|大面积区域内的细微纹理变化|
|7|颜色改变|中高|从第1关技能库里调用|唯一一个穿越来的"老朋友"——但位置隐蔽|


#### 空间节奏 — Challenge阶段的情绪曲线

时间轴   0s──10s──────25s─────────45s─────────60s────75s
         │   │       │           │           │      │
发现差异  ██ (2个)  ███ (2个)   ██ (1个)    ██ (1个) █ (剩1个)
         │   │       │           │           │      │
情绪    轻松  专注   开始紧张    "还有1个"   "找不到"  通关 or
         "老  "这个   "得慢慢找"             "要不要   失利
         套路" 有点                            看广告？"
              难了"

关键设计点：前35秒内找到4处 → 用户感觉"努努力能过"。35-60秒间找到2处 → 时间只剩15秒，还有1处没找到。这个"差一处"的遗憾感需要在60秒时间点精确触发。时间压力 + 差一点 → 看广告的转化窗口。

第2关是广告转化的主战场。75%的未通关用户在这里产生第一次广告观看。

#### 第2关失利后的反馈设计（关键）[v2.2 轮级复活语境修订]

❌ 错误的做法（当前设计隐含的）：

"时间到！" → 弹窗 "看广告复活？" → 感觉像被惩罚

✅ 正确的做法（轮级复活：复活 = 开启新一轮，从 L1 重开）：

┌────────────────────────────────────┐
│  就差一点！你找到了 6/7 处差异     │
│                                    │
│  📊 你的强项：颜色&缺失 ⭐⭐⭐⭐⭐  │
│  📊 需要练习：纹理差异 ⭐⭐        │
│                                    │
│  💡 最后一处藏在木质台面的纹理里    │
│     试试「从左上角开始逐层扫描」    │
│                                    │
│  [ 看广告复活（从L1重开）] ← 你    │
│  [ 分享好友求助 (+1复活) ]  不是    │
│  [ 放弃，今日挑战结束 ]    在求续命 │
│                         你在"决定   │
│                         再来一轮"   │
└────────────────────────────────────┘

设计意图：把"看广告复活"重新定义为"再来一轮的挑战机会"，而不是"失败后的赎罪"。注意轮级复活会从 L1 重新开始（不保留已过的 L1/L2），玩家是用一次复活换"一整轮重来"的机会。同时给出具体建议 → 用户下次面对类似关卡时已经有了策略。

### 第3关：Mastery — "综合维度 + 心流体验"

╔═══════════════════════════════════════════════════════════╗
║ 关卡ID: daily_YYYYMMDD_03_mastery                     ║
║ 通过率目标: 3-8%（不是靠欺骗，是靠极致的视觉密度）       ║
║ 时间限制: 60 秒                                        ║
║ 差异数量: 10 处                                        ║
║                                                       ║
║ 目标：让玩家在前两关学会的所有技能在极限压力下融会贯通    ║
╚═══════════════════════════════════════════════════════════╝

❌ 废除："伪差异"陷阱机制
❌ 废除：RGB差<10的微小色差（那是Bug，不是难度）

✅ 替代：层级复杂度（前景/中景/背景 + 大面积区域 + 纹理密度）
✅ 替代：时间压力下的搜索策略决策（先搜哪里？放弃哪里？）

#### 为什么废除"伪差异"

|||
|---|---|
|用户感受|"这游戏骗我"|"这里太复杂了，我需要更好的策略"|
|失败归因|外部（游戏不公平）|内部（我自己不够快/不够系统）|
|次日行为|觉得被耍 → 不玩了|"明天我一定用更好的方法" → 留存|
|分享动机|"这破游戏有bug"（负面传播）|"第3关太变态了，帮我看看这个角"（求助传播）|


设计法则：让玩家输在自己的能力上，而不是输在设计师的诡计上。前者驱动再来一次，后者驱动卸载。

#### 场景规范

极致的视觉密度：同一个主题世界的最复杂状态。

继续"厨房"案例：第3关是宴会结束后的厨房。锅碗瓢盆堆满台面、食物残渣遍布、墙上有油渍纹理、窗外透进来黄昏的复杂光线。画面中几乎没有"空闲"区域——每一个像素都有信息，每一个信息都可能是差异。

||||
|---|---|---|
|场景复杂度|极高写实，画面填充度 > 85%|视觉信息过载 → 用户无法靠"扫一眼"判断任何区域|
|视觉噪音|大量重复性纹理（瓷砖、木纹、布料）|差异藏在"看起来都一样"的区域里|
|物体数量|40+ 个物体，大量叠放和遮挡|物体间的边界模糊 → 即使是物体缺失也很难一眼看出|
|前景/中景/背景|3层各含30%/40%/30%的差异|用户必须在前两层搜完后，把视线推向深层背景|
|光照复杂度|多种光源混合（窗户光+顶灯+阴影）|自然光影产生大量"看起来像差异"的视觉变化|
|差异类型|1颜色+2缺失+2位移+2大小+2纹理+1综合|五大类型全上场，最后一处需要综合判断|


#### 差异设计（10处，按"视觉层次"排序）

第一层：前景（给你3处，让你有希望）——难度2/10
─────────────────────────────────────────
#1  颜色改变      前景中央的显眼物体      找到时间：5秒内
#2  物体缺失      前景台面边缘            找到时间：10秒内
#3  大小变化      前景独立小物件          找到时间：15秒内

#5  纹理差异      中景桌布/瓷砖的局部纹路   需要"逐层扫描"

关键设计点：35秒处是"绝望谷底"——用户感觉自己找不到任何东西了。这是为两种用户设计的：

- 放弃型用户：在绝望谷底看广告获取提示 → 继续挑战 → 第50秒找到新区域的方法 → 感受到"绝处逢生"的快感
- 坚持型用户：硬着头皮继续搜 → 第45秒自然发现了新的搜索策略（比如从前景转向背景）→ 进入专注的"心流状态"
两类用户在第3关结束后都有正向记忆： 前者记住了"看广告帮我找到了突破口"，后者记住了"我靠自己找到了方法"。

## 差异类型体系（五大类型，完整的难度阶梯）

这是整个关卡系统的底层语言。每种类型的难度都是可控的——通过调整位置、对比度、遮挡关系来精确调节：

||||||
|---|---|---|---|---|
|颜色改变|⭐|颜色差值(大→小)、物体与背景对比度(高→低)|高对比度区域，RGB差>100|中等对比度，RGB差50-80|环境色同化，RGB差<30|
|物体缺失|⭐⭐|物体密集度(少→多)、替代物(有→无)|孤立的显眼物体|密集群中缺少一个|被替代物"填补"了空缺|
|位移|⭐⭐⭐|偏移量(大→小)、参照物(有→无)、遮挡(无→有)|❌ 不使用|有明显参照物的偏移|无参照物，仅凭空间记忆判断|
|大小变化|⭐⭐⭐|缩放比例(大→小)、同类对比(有→无)|❌ 不使用|旁边有同类物体可对比|孤立物体，需凭记忆判断原大小|
|纹理差异|⭐⭐⭐⭐|纹理密度(低→高)、区域面积(小→大)、与周围对比(强→弱)|❌ 不使用|小面积低密度区域|大面积高密度，与周围同化|


差异类型的分层引入 = 技能栈的逐级构建。

第1关只用 ①颜色 ②缺失 → 用户建立了"快速扫描颜色区域+检查物体是否存在"的双重策略。

第2关加入了 ③位移 ④纹理，同时 ①和② 出现在更难的位置 → 用户被迫升级策略。

第3关五类全开，每类的难度都推到了极值 → 只有综合使用全部五种搜索策略的人才能通关。

## 失败与复活机制（轮级复活 + 误找扣时间）[v2.2 取代原"重试机制"章节]

v2.0/v2.1 的"每关2次重试"已废除，统一为「轮级复活」，与开发文档 v1.4 一致。

### 一轮 = L1→L2→L3

- 一次"闯关"为一轮，依次挑战 热身关→加速关→地狱关。
- 任一层失败（时间耗尽 / 误点导致剩余时间<5s归零 / 未找全差异）→ 若仍有复活次数，则开启新一轮，从 L1 重新开始，不保留已通过的 L1/L2 进度。
- 制造"就差 L3 了却要从头再来"的挫败—再来感，体感最贴羊了个羊"整段重来"。
### 复活次数来源（每日上限）

||||
|---|---|---|
|基础复活|2 次/天|每日0点重置|
|广告复活|1 次/天|看激励视频，每日最多1次（条件功能·可热插拔：SDK未接入时入口隐藏，不计入最低可玩基线）|
|分享复活|1 次/天|每日分享，每日最多1次|
|复活卡（背包）|库存量|签到产出，效果 = 1 次轮级复活（从 L1 重开），独立于每日额度，可叠加|


→ 每日最大复活 4 次/天（不含复活卡）。基础 2 次用完后，靠广告/分享各补 1 次（维持变现）；复活卡为额外背包库存。



冷启动降级：游戏首发/广告SDK未接入期，基础复活临时由 2 次上调至 3 次/天（= 基础3 + 分享1 = 4 次），补贴广告复活真空，保证核心循环不断裂。广告接入后降回 2 次，由广告复活1次补位。详见开发文档 v1.4 第 2.5.7 节。

### 新一轮规则

- 每次复活开启的新一轮，三关均使用新图片组（A/B/C 轮换），防止靠记忆通关 L1/L2 后直冲 L3。
- 失败触发点：时间归零 / 误点导致剩余时间<5s归零 / 未找全差异且时间耗尽。
- 边界：




- 第1关即失败 → 复活后仍在 L1（换新图），体验等同重开本轮。
- 基础复活（冷启动期 3 次 / 常态 2 次）+ 广告 1 次 + 分享 1 次 全部耗尽且再次失败 → 当日闯关结束，触发 FOMO（"明天再来"）。广告未接入时"广告1次"项不参与耗尽判定。
- 复活卡为背包库存，独立于每日基础/广告/分享额度，可叠加使用。
### 误找惩罚：扣时间（替代原"惩罚扣分"）

- 规则：玩家点击非差异区（误找）时，剩余时间 −5s。
- 边界定义（构建前必须实现）：




- 剩余时间 < 5s 时误点 → 时间归零，本关判负（强化 "time is life"）。
- 重复点击已找到的差异点 → 不计入误点。
- 已找全差异、进入胜利动画后 → 不再计误点。
- Tuning：每次误点 −5s；内测监测地狱关人均误点次数与通关率联动，若通关率因惩罚跌破 2% 则回调至 −3s（可按关分级 −3/−5/−7）。
- 对关卡时间设计的影响：误找 −5s 会压缩有效探索时间。第1关（90s）里 −5s 几乎无感；第3关（60s）找 10 处，误点 4 次 = −20s（约 1/3 预算），对高手偏狠但对地狱关合理。关卡设计师在"时间限制精确校准"时，应把误找损耗纳入预算：有效时间 ≈ 关卡时限 − 预期误点次数 × 5s。
### 与变现 / 时间经济协同

- 误点 −5s 加速时间耗尽 → 更易触发失败 → 更频繁消耗/购买复活 → 推高人均广告次数（变现引擎）。
- 时间惩罚 + 轮级复活构成"紧张—失败—再来"核心循环，是 FOMO（柱子一）与变现（柱子四）的共同引擎。
### 时间经济（Sources & Sinks）

||||
|---|---|---|
|关卡基础时限|90 / 75 / 60s|进入关卡|
|延长卡|+30s|签到产出，时限内使用|
|分享求助|+15s|每日1次|
|激励视频|+30s（延长）/ +15s（被分享者）|看广告（条件功能·可热插拔：SDK未接入时该来源关闭，时间基线仅剩延长卡 +30 + 分享 +15）|
|去向 Sinks|数值|触发|
|倒计时本身|持续消耗|关卡进行中|
|误找惩罚|−5s/次|点击非差异区|






冷启动 / 无广告降级（详见开发文档 v1.4 第 2.5.7 节）：游戏首发或激励视频 SDK 未接入阶段，所有"看广告"入口关闭，但核心循环不可崩。
- 复活：冷启动期基础复活临时由 2 → 3 次/天（= 基础3 + 分享1 = 4 次，与满血一致）；广告接入后降回 2，由广告复活1次补位，体验无缝。
- 时间：冷启动期仅剩 延长卡 +30 + 分享 +15，靠签到多产延长卡 + 临时放宽地狱关(60→75s) + 提示道具补偿。
- 降级开关：adEnabled、coldStartReviveBase(3/2)、coldStartHellTime(75/60)、coldStartExtendBoost。

注：v2.0/v2.1 的"练习模式 / 道场模式"已废除（v1.3 起），"每关2次重试"也已废除（v1.4 起）。未通关的挫败感正是 FOMO 的驱动力，无需"安慰奖"；轮级复活（换图 + 广告/分享补充）已提供"再来一次"的出口。

## 主题系统设计

### 主题是"世界"，三关是"视角"

每天的主题不只决定了图片内容，还决定了三关的空间叙事。

||||
|---|---|---|
|厨房|整洁早晨|烹饪中午|宴会后深夜|有序→动态→混乱|
|花园|春日初绽|繁花盛开|深秋落叶满地|简单→丰富→密集|
|城市|清晨空街|午间繁忙|夜市霓虹|空旷→人流→光影|
|海滩|退潮沙滩|嬉水人群|日落狂欢后|平坦→散落→狼藉|
|书房|整齐书架|翻阅中的书桌|搬家前的纸箱堆|秩序→使用→废墟|
|动物园|清晨喂食前|日间游览|闭园后的狼藉|安静→热闹→散场|
|菜市场|开市前|早市高峰|收摊后|整洁→拥挤→残余|
|游乐园|开园前|运营中|深夜闭园|空旷→喧闹→寂寥|


每个主题天然自带三幕戏剧结构：建立秩序 → 打破秩序 → 秩序崩溃。玩家在同一主题的三个状态中穿梭，有一种"我见证了这个地方一整天"的满足感。

### 主题轮换策略

每天轮换不同主题，7天一循环：
  周一·厨房  周二·花园  周三·城市  周四·海滩  周五·书房  周六·动物园  周日·菜市场

统一难度：周末和节日不改变难度和玩法
  → 周六的动物园主题与周一的厨房主题难度参数完全一致
  → 节日只换主题内容（如春节用"年夜饭厨房"），不调难度
  → 不产生割裂感，用户每天面对相同的挑战标准

## 空间设计检查清单

以下每一项在一组关卡发布前必须经过验证：

### 可读性检查

第1关 Coach
- [ ] 所有5处差异是否在用户第一眼扫视时就能看到至少3处？
- [ ] 所有差异是否位于前景区域（不涉及深度搜索）？
- [ ] 图中是否存在"意外差异"（AI生成的artifact被误认为差异）？
- [地用时测试：3个测试者在15秒内是否各自至少找到3处？

第2关 Challenge
- [ ] 第1关教过的2种差异类型是否在第2关中仍然可用（但更难了）？
- [ ] 新增的2种差异类型是否有至少1处放在了容易发现的位置？
- [ ] 75秒时间限制下，是否至少有1个测试者无需广告就能通关？
- [ ] 失利后的反馈弹窗是否正确识别了用户的弱项？

第3关 Mastery
- [ ] 10处差异是否全部是真实差异（无伪差异、无AI artifact）？
- [ ] 三层视觉（前景/中景/背景）是否各含合理比例的差异？
- [ ] 60秒是否刚好够"进入心流的人"通关，同时对"没有策略的人"完全不够？
- [ ] 存在至少2种不同的通关搜索策略（证明不是只有一种解法）？

### 公平性检查

- [ ] 每一处差异在发现后，用户能否明确说出"哦，这里确实不一样"？
- [ ] 每一处失败是否让用户感到"是我自己不够好"而非"游戏在耍我"？
- [ ] AI生成的图片之间是否存在"意料之外的差异"（如光照、阴影、透视的微妙偏差）？
- [ ] 差异标注的判定半径是否足够宽容（避免"鼠标点击位置与标注差1px就判定失败"）？
- [ ] 误找惩罚（−5s）是否在地狱关造成"误点4次即损失1/3时限"的过狠体验？内测监测人均误点次数，必要时回调至 −3s。
### 三关关联性检查

- [ ] 三关是否共享同一主题世界？
- [ ] 第1关教过的内容是否在第2关中得以应用？
- [ ] 第1+2关的全部技能是否在第3关中都出现了？
- [ ] 三关的空间复杂度是否明显递增（可以用"画面填充度"量化验证）？
- [ ] 结算页面是否对玩家在上一关的表现做出了反馈（而非孤立的三次结算）？
## 难度调优工具

### 每个关卡的"差异可发现性"分级

把每个差异点标注"可发现性等级"（1-10），在数据库字段中记录，未来可以自动化分析：

{
  "differenceId": "d03",
  "type": "texture",
  "discoverability": 8,
  "discoverabilityFactors": {
    "contrastToSurroundings": 2,
    "areaSize_relativeToScreen": 3,
    "depthLayer": "background",
    "nearbyDistractors": 7,
    "colorDifference_RGB": 18
  }
}

在上线前做"快速难度验证"：
1. 找3个测试者，每人独立玩同一组关卡
2. 记录每个人在每个差异点上的发现时间和点击次数
3. 如果某个差异点3个人都没发现 → 可发现性太高，需要降低难度或是故意的极限点
4. 如果某个差异点3个人都在3秒内发现 → 可发现性太低，对第3关来说太简单

### 时间限制的精确校准

当前方案是固定时间（90/75/60），更精确的做法是：

第1关时间 = 5处差异 × 中位数发现时间 + 15秒缓冲 = 约90秒
第2关时间 = 7处差异 × 中位数发现时间 + 10秒缓冲 = 约75秒
第3关时间 = 10处差异 × 中位数发现时间 + 0秒缓冲 = 60秒
                                                    ↑
                                            关键：去掉缓冲时间
                                        "刚刚好" = "极限"



v2.2 补充：上述"关卡时限"为名义上限，有效探索时间需减去误找损耗。建议校准时按"预期误点次数 × 5s"预留缓冲，地狱关尤其注意——误点 4 次即 −20s，相当于把 60s 名义时限压到 40s 有效时间。

### 内容生产流程（v2.2 更新版）

周度内容生产（需提前2周备好）：

第1天（主题设计）：
  选定下周7天的7个主题 → 每个主题定3个场景状态
  例：厨房 → 早晨/中午烹饪/宴会后
  产出：7×3=21组基础图片描述prompt
  注意：每关需3组图（A/B/C），C组可用A/B的微调变体

第2-3天（AI生成图片）：
  用即梦/Stable Diffusion批量生成
  每关生成2组全新图（A/B）+ 1组变体图（C）
  确保同一个seed下风格一致，A/B/C组主题相同但构图不同

第4天（差异点设计与标记）：
  手动设计每组的差异点
  确保真实差异清晰可辨 + 坐标精确 + 可发现性分级合理
  A/B/C三组的差异位置完全不同（防止记忆通关）
  注：玩家每次轮级复活均换图（A/B/C轮换），因此每组图都需达到"可独立通关"的完整可玩性

第5天（录入+测试）：
  录入云数据库（每关配置3个imageSets）
  找3人快速内测 → 校准"可发现性"分数，并验证误找 −5s 在时限内的体感（尤其地狱关）
