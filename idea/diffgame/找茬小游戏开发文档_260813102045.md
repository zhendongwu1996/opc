# 找茬小游戏 — 开发文档

版本：v1.4 | 日期：2026-08-12 | 作者：单人独立开发

变更5（v1.4）：取消积分系统（零积分），排行榜统一指标为「累积全3关通关次数」；好友/全国榜不清零，省榜为当日本省全3关通关人头数（每日0点归零）；非全通关者按"找到差异数"进度兜底
变更6（v1.4）：误找惩罚由"扣分数(−5)"改为"扣剩余时间(−5s)"

## 一、项目概述

### 1.1 这是什么

一款跨平台（微信 + 抖音）的找茬/找不同小游戏。玩家在两幅高度相似的图片中找出若干处差异，在规定时间内找全即可通关。

### 1.2 核心卖点

每日新关卡：AI 批量生成内容，每天自动上新，用户有理由每天打开

三级排行榜：每日挑战全服统一，好友 / 省 / 全国三级排名，驱动社交裂变

大道至简：一局 60-120 秒，签到送道具 + 成就徽章，无段位 / 皮肤 / 金币 / 内购

零充值承诺：不氪金，全靠实力，所有道具靠签到获得或看广告获取，抓住公平竞争心理

-

零运维成本：基于微信 / 抖音云开发（Serverless），DAU 2000 以内月度账单 ¥0

### 1.3 目标用户

全年龄泛用户，女性偏多（微信小游戏画像）

-

碎片时间消遣型玩家（通勤、排队、睡前）

### 1.4 竞品参考

全民解压找茬、羊了个羊（留存系统标杆）

-

各种找茬类小游戏（玩法验证成熟）

## 二、游戏玩法设计

### 2.1 核心玩法

玩家进入 → 第1关（热身关）
         → 通关率 > 95% → 玩家："这也太简单了吧"
         ↓
         第2关（加速关）
         → 通关率 ~30% → 通过：激动 / 失败：看广告或分享换复活
         ↓
         第3关（地狱关）
         → 通关率 < 5% → 反复失败 → 反复看广告 → 分享求助

一轮 = 第1关 → 第2关 → 第3关。任一层失败（时间耗尽 / 误点耗尽 / 未找全），若仍有复活次数，则开启新一轮、从第1关重新开始（不保留已通过的 L1/L2）。

全3关通关 → 累积全3关通关次数 +1 → 计入排行榜（好友/省/全国）+ 获得成就徽章 + 分享炫耀
未全通关 → 按「找到差异数」进度兜底排名；当日复活额度耗尽则明日再来（FOMO 驱动次日留存）
每日 00:00 → 3关全部刷新 → 昨日关卡作废

### 2.2 核心设计哲学

不做传统找茬的"100关慢慢玩"，而是每天只开放3关，难度指数级爬坡。

核心逻辑：
- 第1关闭着眼过 → 建立信心
- 第2关几乎过不了 → 制造挫败感
- 挫败感 → 看广告复活 → 分享求帮助 → 明天再来

找茬游戏更适合这套模型。 因为"差一点就找到了"的遗憾感比消除类更强——用户会清楚地记得"只差最后一处"。

### 2.3 关卡结构：每天3关

┌─────────────────────────────────────────┐
│              【每日挑战】                  │
│                                         │
│  第1关 | 热身关     通过率 ~95%          │
│    → 差异 5 处，限时 90 秒               │
│    → 图片简单，差异极度明显              │
│    → 设计目标："这也太简单了吧"          │
│                                         │
│  第2关 | 加速关     通过率 ~30%          │
│    → 差异 7 处，限时 75 秒               │
│    → 图片复杂度中等，差异开始隐蔽        │
│    → 设计目标："有点难，但我可以"        │
│                                         │
│  第3关 | 地狱关     通过率 < 5%          │
│    → 差异 10 处，限时 60 秒              │
│    → 图片极复杂，差异极度隐蔽            │
│    → 设计目标："就差一个！再来！"        │
│                                         │
│  每日凌晨 00:00 刷新 → 3关全部更换       │
│  全3关通关 → 累积通关次数+1 + 成就徽章   │
└─────────────────────────────────────────┘

不设练习模式。 理由：
- 大道至简，模块越少越聚焦
- 未通关的挫败感正是 FOMO 的驱动力——"明天一定要过"
- 练习模式会稀释"每日3关"的稀缺感

### 2.4 难度设计详解

#### 第1关（热身关）

||||
|---|---|---|
|差异数量|5 处|少，一眼能看到至少 3 处|
|时间限制|90 秒|平均每处 18 秒，极度宽裕|
|图片风格|简洁卡通/扁平|无复杂纹理干扰|
|差异类型|颜色改变、物体消失|最不需要眼力的类型|
|通过率目标|> 95%|达到"闭眼都能过"的效果|


热身关的唯一目的：让用户产生"我擅长这个"的错觉。

#### 第2关（加速关）

||||
|---|---|---|
|差异数量|7 处|前5处容易，最后2处需要仔细看|
|时间限制|75 秒|开始有紧迫感|
|图片风格|中等写实|有纹理和颜色干扰|
|差异类型|大小变化、纹理差异、位置偏移|需要专注|
|通过率目标|~30%|有人过有人不过，拉开差距|


#### 第3关（地狱关）

||||
|---|---|---|
|差异数量|10 处|多到用户数不清|
|时间限制|60 秒|平均每处只有 6 秒|
|图片风格|高度写实/复杂场景|满满都是视觉噪音|
|差异类型|微小色差、极小位移、纹理变化、大小变化|极度隐蔽|
|特殊机制|无（不设伪差异）|难度来自真实视觉复杂性|
|通过率目标|< 5%（最好 2-3%）|每天只有极少数人通关|


地狱关不使用任何欺骗机制。 难度完全来自：
- 图片复杂度（高密度场景、视觉噪音）
- 差异隐蔽度（低对比度、小位移、纹理同化）
- 时间压力（60秒找10处，且误找每次 −5s 压缩有效时间）

设计原则：让玩家输在自己的能力上，而不是输在设计师的诡计上。前者驱动再来一次，后者驱动卸载。

### 2.5 轮级复活机制

#### 2.5.1 核心模型：一轮 = L1→L2→L3

一次"闯关"为一轮，依次挑战 热身关→加速关→地狱关。

任一层失败（时间耗尽 / 误点导致剩余时间归零 / 未找全差异）→ 若仍有复活次数，则开启新一轮，从 L1 重新开始，不保留已通过的 L1/L2 进度。

-

制造"就差 L3 了却要从头再来"的挫败—再来感，体感最贴羊了个羊"整段重来"。

#### 2.5.2 复活次数来源（每日上限）

||||
|---|---|---|
|基础复活|2 次/天|每日0点重置|
|广告复活|1 次/天|看激励视频，每日最多1次（条件功能·可热插拔：广告SDK未接入时入口隐藏/禁用，不计入最低可玩基线）|
|分享复活|1 次/天|每日分享，每日最多1次|
|复活卡（背包）|库存量|签到产出，效果 = 1 次轮级复活（从 L1 重开），独立于每日额度，可叠加|


→ 每日最大复活 4 次/天（不含复活卡）。基础 2 次用完后，靠广告/分享各补 1 次（维持变现）；复活卡为额外背包库存。

冷启动降级：游戏首发/广告SDK未接入期，基础复活临时由 2 次上调至 3 次/天（= 基础3 + 分享1 = 4 次），以补贴广告复活真空，保证核心循环"紧张—失败—再来"不断裂。广告接入后基础复活降回 2 次，由广告复活1次补位，体验无缝。详见 2.5.7。

#### 2.5.3 新一轮规则

每次复活开启的新一轮，三关均使用新图片组（A/B/C 轮换），防止靠记忆通关 L1/L2 后直冲 L3。

失败触发点：时间归零 / 误点导致剩余时间归零 / 未找全差异且时间耗尽。

边界：

第1关即失败 → 复活后仍在 L1（换新图），体验等同重开本轮。

基础复活（冷启动期 3 次 / 常态 2 次）+ 广告 1 次 + 分享 1 次 全部耗尽且再次失败 → 当日闯关结束，触发 FOMO（"明天再来"）。广告未接入时"广告1次"项不参与耗尽判定。

-

复活卡为背包库存，独立于每日基础/广告/分享额度，可叠加使用。

#### 2.5.4 误找惩罚：扣时间（替代原"惩罚扣分"）

规则：玩家点击非差异区（误找）时，剩余时间 −5s。

边界定义（构建前必须实现）：

剩余时间 < 5s 时误点 → 时间归零，本关判负（强化 "time is life"）。

重复点击已找到的差异点 → 不计入误点。

已找全差异、进入胜利动画后 → 不再计误点。

-

Tuning：每次误点 −5s；内测监测地狱关人均误点次数与通关率联动，若通关率因惩罚跌破 2% 则回调至 −3s（可按关分级 −3/−5/−7）。

#### 2.5.5 与变现/时间经济协同

误点 −5s 加速时间耗尽 → 更易触发失败 → 更频繁消耗/购买复活 → 推高人均广告次数（变现引擎）。

-

时间惩罚 + 轮级复活构成"紧张—失败—再来"核心循环，是 FOMO（柱子一）与变现（柱子四）的共同引擎。

#### 2.5.6 时间经济（Sources & Sinks）

||||
|---|---|---|
|关卡基础时限|90 / 75 / 60s|进入关卡|
|延长卡|+30s|签到产出，时限内使用|
|分享求助|+15s|每日1次|
|激励视频|+30s（延长）/ +15s（被分享者）|看广告（条件功能·可热插拔：SDK未接入时该来源关闭，时间基线仅剩延长卡 +30 + 分享 +15）|
|去向 Sinks|数值|触发|
|倒计时本身|持续消耗|关卡进行中|
|误找惩罚|−5s/次|点击非差异区|


#### 2.5.7 冷启动 / 无广告降级策略（可热插拔）

游戏首发或激励视频SDK未接入阶段，所有"看广告"入口关闭，但核心循环不可崩。降级原则如下：

广告类入口统一标注"条件功能·可热插拔"：激励视频（延长+30s / 提示一处差异 / 复活1次 / 被分享者+15s）在SDK未接入时隐藏或禁用，不计入最低可玩基线，避免"无广告即报错"。

复活降级（按开关切换）：

冷启动期：基础复活 3 次/天（临时上调）+ 分享复活 1 次 = 4 次/天基线（不含复活卡），与满血状态（基础2+广告1+分享1）体验一致。

常态（接广后）：基础复活降回 2 次/天，广告复活 1 次补位，仍为 4 次/天。

实现：服务端 adEnabled 开关，客户端按开关显示/隐藏广告复活入口，基础复活次数由同一开关驱动（3 / 2）。

时间延续降级：冷启动期时间来源仅剩 延长卡 +30s + 分享 +15s。补偿措施二选一或并行：

签到/登录奖励临时多产延长卡（如第1-3天每日保底1-2张，代替原本需看广告补的时间）；

必要时临时放宽地狱关基础时限（60s → 75s），降低时间压力，待广告接入后回调。

提示广告降级：看广告"显示一处差异"冷启动期不可用，由 签到产出的"提示道具" 或临时降低地狱关差异数（如10→8处）补偿，避免纯靠运气。

被分享者体验降级：被分享者进场后"看广告+时长"关闭，仅保留 30s 限时体验（仍可独立计数、仍可裂变，只是体验略短）。

预期收入归零属正常：冷启动期无商业化补偿，目标为验证留存与裂变；广告接入后人均广告次数回归 4-6 次/天（详见 3.1 柱子四）。

降级开关清单：adEnabled（广告复活/延长/提示/被分享者时长总开关）、coldStartReviveBase（基础复活次数：3/2）、coldStartHellTime（地狱关时限：75/60）、coldStartExtendBoost（签到延长卡加成：开/关）。

### 2.6 排行与进度规则（零积分）

#### 2.6.1 核心指标：累积全3关通关次数

定义：玩家历史上"当日3关全部通关"的累计次数。每次全3关通关 +1。

仅"全3关通关"计入，单关通关不计入（避免 L1 95% 通过率稀释指标、制造无效噪音）。

-

该指标同时作为"百关斩"成就的进度来源（累计 100 次全通关解锁）。

#### 2.6.2 三级排行榜（统一指标）

||||
|---|---|---|
|好友榜|累积全3关通关次数|微信好友间按累积次数排序|不清零（耐久身份）|
|全国榜|累积全3关通关次数|全服按累积次数排序|不清零|
|省榜|当日本省全3关通关人头数|本省当日全3关通关玩家去重计数|每日0点归零|

省榜逻辑：个人全通关 = 为省份 +1 人头，驱动"今日帮广东冲第一"的每日战争与裂变。

-

个人/好友/全国榜为累积（长期身份与进度目标）；省榜保留每日窗口以保住每日紧迫感（入坑时间不会锁死省榜）。

#### 2.6.3 进度兜底（非全通关者）

未达成全3关通关的玩家不在"通关次数"榜占位，改为按进度展示与次级排序：

进度值 = 找到差异数 / 当日3关总差异数（好友榜内未通关者按此排序）。

用途：保证中腰部玩家仍有可见位置与进步感，不出现"全0块"。

-

此进度值即原"基础分"项（找出差异数/总差异数×100），但仅作展示/兜底，不进入任何积分。

#### 2.6.4 误找惩罚：扣时间（详见 2.5.4）

点击非差异区 −5s 剩余时间；剩余归零判负、重复点已找到不算、胜利后不计。

#### 2.6.5 零积分声明

取消全部积分/分数系统（基础分、时间奖励、惩罚扣分均移除），排行榜只用"累积全3关通关次数"单一指标。

### 2.7 分享求助系统

每日可分享 1 次。 分享是策略性资源，玩家需要选择最佳时机使用。

#### 分享的两个使用场景

||||
|---|---|---|
|关卡内延长|剩余时间 ≤ 15s 时弹出|+15 秒延长时间|进入同一关卡，限时 30 秒|
|关卡失败复活|复活额度用完后（每日基础+广告+分享计数）|+1 次轮级复活（从 L1 重开）|开启新一轮，新图片组|

两种场景共用同 1 次每日分享配额。用了就不能再用，第二天 00:00 恢复。

#### 被分享者的体验

好友点击分享链接 → 进入小游戏 → 直接跳转到对应关卡
  → 限时 30 秒（不论原关卡时限）
  → 可看激励视频广告获取额外时长（每次 +15s，条件功能·接广后启用；冷启动期此入口关闭，仅保留 30s 限时体验）
  → 独立计数（累积全3关通关次数），不影响分享者的成绩
  → 不能再次分享该关卡（防止链式传播）

#### 分享规则

每天只能分享 1 次（所有关卡共享配额）

只能分享自己当前正在玩的关卡

不能分享别人发给自己的关卡

-

被分享者进入的关卡图片组与分享者当前图片组相同

#### 方案评估结论

|||
|---|---|
|每日1次限制|✅ 制造稀缺，玩家策略性选择分享时机|
|分享者 +15s|✅ 直接利益驱动，不是"帮我"而是"互利"|
|被分享者 30s|✅ 快速体验不变成"代打"，意犹未尽反而促成下载|
|只能分享自己的关卡|✅ 防止链式分享刷次数|
|被分享者也能看广告|✅ 双重广告收入（分享者 + 被分享者）|
|分享换轮级复活|✅ 每日最多1次分享复活，与广告复活并列，维持变现|

## 三、留存 & 增长系统

### 3.1 四柱留存模型

#### 柱子一：内容引擎（用户凭什么明天还来）

|||
|---|---|
|每日新3关|每天凌晨刷新 3 关新图，全服统一，错过就没了|
|轮级复活换图|每次复活开启新一轮，使用不同图片组，防止记忆通关，每次都是新挑战|
|地狱关通过率|第3关仅 2-3% 人通过 → 未通关者的 FOMO："明天一定要过"|
|限时稀缺感|昨天的关卡昨天玩，过期不候|
|统一难度|周末、节日不改变难度和玩法，不产生割裂感，用户每天面对相同的挑战标准|


#### 柱子二：社交钩子（用户凭什么帮你拉人）

三级排行榜（好友 / 省 / 全国）——排名即身份。

|||
|---|---|
|好友榜|微信好友之间比累积全3关通关次数|
|省榜|当日本省全3关通关人头数（每日0点归零）|
|全国榜|全服比累积全3关通关次数|


分享求助系统（详见 2.7）：

|||
|---|---|
|三级排行榜|好友榜 + 省榜 + 全国榜，同一份成绩三种排名|
|好友成绩悬浮窗|进关卡前展示 3 个微信好友最好成绩|
|分享求助|每日1次，+15s 延长或 +1 轮级复活，被分享者 30s 体验|
|抖音录屏分享|通关后一键生成录屏发抖音，带游戏入口|


#### 柱子三：成长系统（为什么舍不得卸载）

设计原则：大道至简。只有两样东西——签到（送道具）和成就徽章。
已砍掉：赛季段位、皮肤、收藏品、金币积分、内购道具包。 理由：
- 段位与排行榜重复——玩家已经能比"朋友圈/省/全国"，再搞段位只是多一套数字
- 皮肤/收藏品需要美术资源和持续运营，违背"轻量"定位
- 金币无消费出口（皮肤已删），金币体系整体废除
- 内购违背"零充值，全靠实力"的核心承诺

##### 每日签到（送道具，非金币）

道具只有两种，心智极简：

|||
|---|---|
|延长卡|时间用完前使用，+30 秒|
|复活卡|失败后使用，轮级复活（从 L1 重开）|


7 天签到循环（断签归零，第 8 天回到第 1 天）：

|||
|---|---|
|1|延长卡 ×1|
|2|延长卡 ×1|
|3|复活卡 ×1|
|4|延长卡 ×2|
|5|复活卡 ×1 + 延长卡 ×1|
|6|延长卡 ×2|
|7|复活卡 ×2|


为什么这样设计：
- 第 7 天是锚点：玩家连续签 6 天后，第 7 天的大奖就在眼前，断签=前功尽弃——这是每天打开的最大驱动力
- 奖励与地狱关强绑定：道具只能在最难的关卡救你，签到直接服务于"明天把第 3 关打过去"的执念
- 道具不冲击广告收入：地狱关平均需要 3-6 次复活，签到每天只产 1-2 个道具，只覆盖需求的 30-40%，剩余缺口仍靠广告填补
- 断签归零："今天不签，之前的都白费"

##### 成就徽章（永久累计，炫耀资本）

|||
|---|---|
|鹰眼大师|累计找到 1000 处差异|
|百关斩|累计全3关通关 100 次|
|地狱征服者|单日全3关通关（每日挑战）|
|签到狂人|连续签到 7 天|
|闪电侠|30 秒内通关一关|
|社交达人|累计 10 个好友点击分享求助|
|暗夜守卫|凌晨 0-5 点玩过游戏（反向成就，引发好奇）|


每枚徽章生成精美分享图——"我拿到了地狱征服者，你能吗？"——这是免费的裂变素材。

#### 柱子四：变现平衡（赚钱但不赶人）

核心逻辑：零充值，纯广告。 所有帮助都通过广告或签到道具获得，公平竞争。

注：下表"激励视频"各行均为条件功能·可热插拔，激励视频SDK接入后生效；冷启动/无广告期这些入口关闭，对应能力由签到道具托管（见 2.5.7）。

||||
|---|---|---|
|激励视频|时间用完 → 看广告延长 30 秒|⭐⭐⭐⭐⭐|¥40-60|
|激励视频|找不全 → 看广告显示一处差异位置|⭐⭐⭐⭐⭐|¥40-60|
|激励视频|复活次数用尽 → 看广告换 1 次复活（每日最多1次）|⭐⭐⭐⭐⭐|¥40-60|
|激励视频|被分享者进入后 → 看广告获取额外时长|⭐⭐⭐⭐|¥40-60|
|Banner|关卡结算页底部|⭐⭐⭐|¥2-5|
|强制插屏|❌ 不做——30% 用户直接流失|—|—|

无内购。 零充值是核心卖点，也是营销口号："全靠实力，不氪金。"

道具与广告双通道并存——不想看广告的用签到攒的道具，愿意看的看广告。两者服务不同玩家，互不侵蚀。但没有任何"花钱变强"的通道。

预期人均广告次数（基于地狱关 + 轮级复活模型）：

第1关尝试（95%用户）           → 0-1 次（偶尔看延长/提示）
第2关尝试（80%用户进入）       → 1-2 次（延长/提示/复活）
第3关地狱（90%用户进入）       → 3-6 次（反复复活+延长+提示）
被分享者进入（10-15%用户触发） → 1-2 次（获取额外时长）

加权平均：人均 4-6 次激励视频/天
对比传统找茬游戏：人均 1-2 次/天
→ 轮级复活 + 误找−5s 直接推高广告收入（误找加速失败→更频繁消耗复活）。

冷启动/无广告期收入说明：上述广告变现在激励视频SDK未接入前为 0。该阶段靠"基础复活临时上调至3次 + 签到多产延长卡"维持核心循环（见 2.5.7），无商业化补偿属预期内，目标是先验证留存与裂变而非变现。广告接入后按上表恢复，人均广告次数回归 4-6 次/天。

### 3.2 前 30 天增长路线

Week 1（上线验证）
  邀请 50 个种子用户测试
  核心关注：第3关通过率是否在 2-5% 范围内
  → 如果太高 → 增加图片复杂度 + 缩短时间
  → 如果太低（< 1%）→ 降低图片复杂度 + 延长时间
  目标：次留 > 40%

Week 3（买量验证）
  微信 + 抖音各投 ¥200 测试买量成本
  看首日 ROI 是否 > 0.5
  目标：DAU 500-1000

Week 4（数据调优）
  分析漏斗：进游戏 → 第1关通过率 → 第2关通过率 → 第3关尝试率 → 第3关通过率
  关键：第3关尝试率不能掉（说明第2关没有劝退太多人）

## 五、运营方案

### 5.1 内容生产流程（每周一次，3-4 小时）

### 6.1 广告收入估算（纯广告，零内购）

轮级复活 + 误找−5s 驱动广告频次提升：

DAU 2000 × 人均 4.5 次激励视频 × eCPM ¥40 ÷ 1000 = ¥360/天
DAU 5000 × 人均 5 次激励视频 × eCPM ¥40 ÷ 1000 = ¥1000/天
DAU 10000 × 人均 6 次激励视频 × eCPM ¥40 ÷ 1000 = ¥2400/天

轮级复活提供了额外广告触发点（看广告换复活，每日最多1次），且误找−5s 加速时间耗尽、推高复活消耗；"零充值"带来的口碑和用户信任能提升留存。
