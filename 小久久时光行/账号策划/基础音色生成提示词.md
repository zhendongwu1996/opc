# 小久久时光行｜基础音色生成提示词

## 使用说明

这两段提示词用于 Seedance 2.5 生成小久久和熊茂茂的基础声音参考视频，再从视频中提取音频，作为后续配音的声音样本。

- 每次只生成一个角色，不能让两个角色同时出现或说话。
- 使用对应角色的固定参考图，保持脸部、服装和外形不变。
- 画面使用固定近景或中近景，方便观察口型；声音比画面更重要。
- 提示词要求无音乐、无音效、无环境声、无旁白，后期只保留角色人声。
- 如果平台单次生成时长有限，可以按自然停顿拆成两段，再拼接音频；拼接后每个角色的完整样本仍不要超过30秒。
- 如果生成结果超过30秒，优先删除开头和结尾的空白，不要用明显加速的方式压缩声音。

## 一、小久久基础音色提示词

### 可直接粘贴给 Seedance 2.5

```text
使用上传的小久久角色参考图，生成一段约22至26秒的视频。画面为温馨儿童房，小久久一个人坐在地毯上，使用中近景固定机位，面向镜头自然说话，动作简单，只做轻微点头、眨眼和手势，口型与普通话台词同步。不要出现其他人物、玩偶或第二个声音。

小久久的声音是3岁左右的中文普通话童声：明亮、柔软、干净、亲近，语速稍慢，短句清楚，带自然的好奇和开心。声音不能尖锐，不能过度撒娇，不能像成人缩小版，不能使用夸张的动画腔。每句之间自然停顿约0.5至1秒，完整说完所有台词。

声音只保留小久久的人声：不要背景音乐，不要环境声，不要魔法音效，不要笑声铺底，不要旁白，不要回声，不要字幕和画面文字。录音感觉像安静房间里的干净近距离配音。

请按以下顺序说出全部台词：

“大家好，我是小久久。”
“你好呀，你叫什么名字？”
“咦，这是什么呀？”
“我想看一看。”
“真的呀？”
“我知道啦。”
“我们一起出发吧！”
“谢谢你，熊茂茂。”
```

### 小久久声音检查重点

| 检查项 | 合格表现 |
|---|---|
| 年龄感 | 听起来像3岁左右的孩子，但吐字仍然清楚。 |
| 音色 | 明亮柔软，不尖、不刺耳。 |
| 语速 | 比成人稍慢，每句话听得完整。 |
| 情绪 | 有好奇、惊喜和开心的变化，但不大喊大叫。 |
| 稳定性 | 八句台词前后音色一致，没有忽高忽低或忽男忽女。 |
| 清洁度 | 没有音乐、环境声、回声和其他人声。 |

## 二、熊茂茂基础音色提示词

### 可直接粘贴给 Seedance 2.5

```text
使用上传的熊茂茂角色参考图，生成一段约22至26秒的视频。画面为温馨、安静的儿童房，熊茂茂一个人站在小久久常用的房间里，使用中近景固定机位，面向镜头自然说话，动作简单，只做轻微点头、抬手和温和微笑，口型与普通话台词同步。不要出现小久久、其他人物或第二个声音。

熊茂茂的声音是温暖、圆润、可靠的中文普通话陪伴型声音：音高比小久久略低，吐字清楚，语速平稳，耐心而不说教，像一位亲切的大朋友。声音不能过度低沉，不能像新闻播音员，不能像课堂老师，不能使用夸张的卡通腔或机械的AI腔。每句之间自然停顿约0.5至1秒，完整说完所有台词。

声音只保留熊茂茂的人声：不要背景音乐，不要环境声，不要魔法音效，不要笑声铺底，不要旁白，不要回声，不要字幕和画面文字。录音感觉像安静房间里的干净近距离配音。

请按以下顺序说出全部台词：

“大家好，我是熊茂茂。”
“别着急，我们慢慢看。”
“你先观察一下，发现了什么？”
“你看得很仔细。”
“我来告诉你一个小知识。”
“我们一起找答案。”
“记住了吗？我们再说一遍。”
“做得真棒，我们继续出发！”
```

### 熊茂茂声音检查重点

| 检查项 | 合格表现 |
|---|---|
| 陪伴感 | 像耐心的大朋友，不像老师训话。 |
| 音色 | 温暖圆润，略低于小久久，但不能浑浊。 |
| 语速 | 平稳、清楚，解释句有自然停顿。 |
| 情绪 | 有安抚、引导、鼓励和开心的变化。 |
| 稳定性 | 八句台词保持同一年龄感、同一音色和同一身份。 |
| 清洁度 | 没有音乐、环境声、回声和其他人声。 |

## 三、音频提取与保存

生成视频后，只提取角色人声，保存为 WAV 格式。建议文件名：

```text
XJJ_voice_master_v01.wav
XMM_voice_master_v01.wav
```

第一次生成后不要马上批量制作。先分别试听两段样本，确认音色、年龄感、语速和清晰度，再固定为后续视频使用的基础声音。后续台词生成时，始终使用同一角色的声音参考视频、声音 ID和参数。
