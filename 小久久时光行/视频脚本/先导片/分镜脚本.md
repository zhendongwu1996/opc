**固定风格词**（每段 3D 提示词已内置，无需重复粘贴）：

- 风格：高质感 3D 动画电影风格，皮克斯级渲染，温暖柔和，无文字
- 场景：男孩系儿童房，浅蓝/米白/浅木色，圆形地毯、矮床、书架、窗光
- 角色：外形与上传参考图完全一致，3 岁男孩 + 棕色小熊

### 2. 推荐生成流程（提高一次通过率）

```
步骤 1：用 Seedream 生成并固定「儿童房正面全景」→ 全片场景基准
步骤 2：仅生成镜 3（8秒）→ 验收角色+场景是否稳定
步骤 3：提取镜 3 最后一帧 → 作为镜 4 首帧参考
步骤 4：按镜 4→5→6…顺序链式生成（每镜首帧=上一镜末帧）
步骤 5：台词、BGM、音效全部后期配音，生成时不强求口型
步骤 6：镜 1–2 建议实拍/静帧+后期特效，不必强行 Seedance
```

### 4. 参数建议

- **时长**：与分镜表一致，不要缩短（短了台词贴不上）
- **镜头**：优先「固定机位」；推镜/上摇幅度要小
- **动作**：每镜只写 1 个主动作 + 1 个被动作
- **声音**：生成时关闭 BGM/音效；台词后期贴（成功率更高）
- **文字**：所有提示词均含「不要文字、字幕、logo」

### 5. 单镜验收清单（生成后立即检查）

- [ ] 小久久是男孩，外形与参考图一致
- [ ] 儿童房配色为男孩系（浅蓝米白），非粉色公主风
- [ ] 熊茂茂觉醒后不再变回玩偶（镜 7 起）
- [ ] 画面内无乱码文字
- [ ] 动作与提示词一致，无多余_walking/奔跑
- [ ] 与上一镜衔接：人物位置、光线、服装无跳变

### 6. 一次通过的关键原则

1. **先锁场景，再锁角色，最后做魔法特效**
2. **链式首帧**：镜 3 通过后，后续全部用「上一镜末帧」作首帧
3. **对话镜拆人**：一镜只有一个小久久或熊茂茂在说话
4. **复杂镜降级**：天幕/通道/发光花若失败，先生成「人物+简单光效」版，特效后期合成
5. **不要一次生成 18 镜**：先跑通 3→6→7→10 四条关键镜，再批量
