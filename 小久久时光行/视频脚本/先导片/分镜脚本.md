### 2. 推荐生成流程（提高一次通过率）

```

步骤 2：仅生成镜 3（8秒）→ 验收角色+场景是否稳定

步骤 5：台词、BGM、音效全部后期配音，生成时不强求口型
步骤 6：镜 1–2 建议实拍/静帧+后期特效，不必强行 Seedance
```

### 4. 参数建议

- **时长**：与分镜表一致，不要缩短（短了台词贴不上）
- **镜头**：优先「固定机位」；推镜/上摇幅度要小
- **动作**：每镜只写 1 个主动作 + 1 个被动作
- **声音**：提示词中已写入台词；生成时只保留角色普通话，关闭 BGM/音效，最终可用固定角色音频替换。
- **文字**：所有提示词均含「不要文字、字幕、logo」

### 5. 单镜验收清单（生成后立即检查）

- [ ] 小久久是男孩，外形与参考图一致
- [ ] 儿童房配色为男孩系（浅蓝米白），非粉色公主风
- [ ] 熊茂茂觉醒后不再变回玩偶（镜 7 起）
- [ ] 画面内无乱码文字
- [ ] 动作与提示词一致，无多余_walking/奔跑
- [ ] 与上一镜衔接：人物位置、光线、服装无跳变

### 6. 一次通过的关键原则

1. **先锁场景，再锁角色，最后做魔法特效**
2. **链式首帧**：镜 3 通过后，后续全部用「上一镜末帧」作首帧
3. **对话镜拆人**：一镜只有一个小久久或熊茂茂在说话
4. **复杂镜降级**：天幕/通道/发光花若失败，先生成「人物+简单光效」版，特效后期合成
5. **不要一次生成 18 镜**：先跑通 3→6→7→10 四条关键镜，再批量

## 三、Seedance 2.5 提示词（可直接粘贴）

> **用法**：复制对应镜号整段 → 上传该镜「首帧参考 + 角色参考 + 场景参考」→ 设置时长 → 生成。
>
> **通用否定**（已写入每段，无需另加）：不要文字、字幕、logo、水印、额外人物、恐怖元素、快速跳切、角色变形、粉色公主房。

### 镜 1｜真人合照｜8秒

**参考素材**：真人合照  
**建议**：优先用真实照片，不必 Seedance 生成

```text
【镜1｜时长8秒｜景别：中近景｜镜头：固定机位】
【参考素材：上传的真人合照】
场景：真实的温馨儿童房，柔和的室内暖光，生活照片质感。
角色：3岁中国男孩小久久，穿居家便服，紧紧抱着棕色小熊阿贝贝玩偶，外形以真人合照为准。
动作：小久久看向镜头，自然开心，保持抱住玩偶的姿势，画面稳定，不做复杂动作。
台词：无台词，只保留安静画面，后期从本镜开始铺入温暖轻柔的背景音乐。
声音：不生成角色人声、环境声或音效，只保留后期BGM空间。
画面风格：真实照片质感，不要动画风格，不要过度磨皮。
负面约束：不要其他人物，不要改变小久久的脸和服装，不要文字、字幕、logo、水印、卡通变形。
```
