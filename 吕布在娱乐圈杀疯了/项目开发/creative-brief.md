# 《吕布在娱乐圈杀疯了》创作简报

## 1. 项目定位

- **题材**：古代名将穿越现代、娱乐圈逆袭、职场轻喜剧、热血群像。
- **形态**：AI 漫剧，100 集连续短剧；建议单集 90—120 秒。
- **核心卖点**：真吕布误入“吕布被斩”片场；古人的真实反应被现代人当成神级演技；他以战场经验破解片场、综艺和资本困局，最终从任人摆布的替身成长为制定规则的影视公司创始人。
- **目标体验**：每集至少兑现一种回报——古今错位笑点、可核对的专业高光、公开反转、人物关系位移或长线秘密推进。
- **暂定宣传语**：上一世，他被曹操斩于白门楼；这一世，他要让整个娱乐圈为他搭一座封神台。

## 2. 不可更改的故事事实

1. 吕布兵败将被曹操斩首，刀落时一缕魂魄进入轮回。
2. 他穿越现代，附身在街头饿死的流浪汉“吕步”身上，但不会获得原身的任何记忆；“吕步”这个名字来自随身证件。
3. 两人容貌、身高神似；现代身体因长期挨饿十分虚弱，不能开局无敌。
4. 天亮后，吕步经过古装电影片场，现场正拍“吕布兵败被斩”。
5. 顶流男星不肯亲演受刑镜头，剧组临时寻找群演；星探苏晚晴发现吕步。
6. 吕步吃饱、洗脸、剃须、换上战甲后神似真正的吕布，震惊全场。
7. 开拍时吕步拒跪，被众人合力压跪；导演误以为是真实感极强的表演。
8. “曹操”下令斩首后，吕步暴起追打曹操、刘备、张飞的演员，怒骂“曹贼”“大耳贼”“环眼贼”，闹剧最终被众人制止。
9. 苏晚晴认可他的表演潜力并逐步包装他；他经历科技、生活和行业规则带来的闹剧，走上演员巅峰。
10. 结局中吕步创立影视公司，获得作品与公司的控制权，并签下其他被低估的演员。

## 3. 创作边界与基调

- 以爽、燃、笑为主，情感为辅；不开系统，不让主角拥有超自然武力。
- 他只保留吕布本人的前世记忆，不继承原身吕步的记忆、常识或习惯；现代信息必须通过亲眼观察、他人教导和调查获得。
- 现代肉身只保留饥饿、旧伤等生理状态，不提供任何“身体自动会用”的现代技能，确保主角对手机、交通、支付、法律和娱乐行业始终真正陌生。
- 吕布的武艺、骑术、战场判断和识人经验可以迁移；现代法律、表演、商业、舆论必须重新学习。
- 身体恢复遵循“营养—训练—复健”过程，前 20 集仍会因虚弱吃亏。
- **前 20 集笑料原则**：每集至少 1 个“古人误读现代事物”的可见笑点，且笑点必须推动剧情（引发赔偿、直播、迟到、被围观、被苏晚晴教育），不能只是插科打诨。吕布惯用“阵、妖、机关、军粮、主公”等词汇误读现代物；**交通类笑料只保留摩托、汽车各一次**，避免反复把现代载具当成战马。
- 不美化暴力解决现代问题。吕步每次想“斩”，都要被法律、合同、舆论或同伴迫使换一种赢法。
- 感情线采用克制慢热：吕步与苏晚晴由利用、结盟到生死与共，结局以并肩创业为主，不挤占事业线。
- 曹操、刘备、张飞等历史人物只以吕布的记忆和现代演员对应制造错位，不设“全员穿越”。

## 4. 戏剧承诺

吕步用“强者夺回主动、受辱当场反击”的旧策略争取尊严与演员位置时，娱乐行业的合同、镜头、舆论、流量和资本会把他的冲动转化为法律与名誉代价；观众反复看到他将战场能力转译为可被镜头、观众和成绩验证的表演能力，也看到他从“谁敢压我，我便杀谁”成长为“我定规则，让有本事的人不必再跪”。

### 主题张力

- **武力赢得服从** ↔ **作品赢得认同**
- **一人无双** ↔ **相信团队**
- **宁折不跪的尊严** ↔ **为更大的目标暂时低头**
- **被大众消费的“吕布”** ↔ **吕步自己选择成为谁**

## 5. 主要人物

### 吕步 / 吕布

- **表层目标**：吃饱活下去，洗清疯子标签，成为无人敢轻贱的演员。
- **深层追求**：证明自己并非“三姓家奴”式的笑柄，并获得一次不由他人书写的结局。
- **优势**：极强镜头压迫感、战场判断、骑术兵器、危险感知、记忆力、领袖气场。
- **盲区**：把服从等同忠诚，把让步等同屈辱；擅长冲阵，不擅长规则和长期经营。
- **弧光**：孤狼求生 → 学会表演与守约 → 为团队承担 → 掌握规则 → 给新人不下跪的机会。

### 苏晚晴

- **身份**：曾是曜星娱乐金牌经纪人，因拒绝替公司制造艺人黑料而被封杀，如今经营濒临倒闭的“晚风工作室”。
- **目标**：用一个真正有能力的演员翻身，并拿到曜星篡改合同与操纵舆情的证据。
- **优势**：懂市场、镜头、合同和人心；能把吕步的野性变成作品卖点。
- **盲区**：把人当项目管理，不肯承认自己需要伙伴。
- **与吕步的压力**：她要他服从现代规则，他要她先证明值得追随；两人最终从“经纪人与艺人”变成共同制定规则的合伙人。

### 唐小满

- **身份**：晚风工作室剪辑兼运营，社恐技术宅，吕步的现代生活老师。
- **作用**：承担手机、支付、直播、网络梗等错位喜剧；也是第一个把吕步当“人”而非流量素材的人。
- **弧光**：只敢躲在屏幕后 → 敢公开证据、站到镜头前。

### 顾子昂

- **身份**：曜星娱乐一线顶流，最初饰演吕布却拒绝危险镜头。
- **目标**：守住“娱乐圈唯一战神”的流量标签。
- **筹码**：粉丝、品牌、平台资源和公司公关。
- **弧光**：轻蔑吕步 → 害怕被取代 → 主动栽赃 → 被资本抛弃 → 最终承认输给作品，而非输给身份。

### 陈世昌

- **身份**：曜星娱乐副总裁，苏晚晴旧上司。
- **目标**：证明明星可以被数据和合同制造，任何不可控的人都必须被收编或摧毁。
- **筹码**：平台排期、营销号、对赌合同、品牌关系、剪辑权。
- **反制升级**：抢角色 → 制造舆情 → 合同锁人 → 封杀项目 → 资本围猎 → 伪造安全事故。

### 梁正雄

- **身份**：片场饰演曹操的老戏骨。
- **作用**：从被吕步追砍的“曹贼”变成其表演导师；教会他“跪下也可以是为了下一场站起来”。

### 刘玄、张天冀

- **身份**：分别饰演刘备、张飞的演员；刘玄圆融善谈，张天冀兼动作指导。
- **作用**：前期错位笑点，中期成为片场盟友；两人的现代人格不断修正吕步对历史人物的单一判断。

### 林鹿

- **身份**：童星出身的实力女演员，因拒绝饭局被边缘化。
- **作用**：吕步首个真正意义上的搭档，后期成为新公司的第一位签约演员；与吕步是战友情，不走三角恋。

## 6. 十篇章状态运动

1. **白门楼再斩（EP001—010）**：穿越、片场暴走、视频爆红；吕步为一顿饭签下第一份现代合约。
2. **现代生存战（EP011—020）**：补证件、学手机、练身体、做群演；密集呈现古人误读现代的反差笑料，他第一次明白“镜头里赢”不同于“现实里打赢”。
3. **替身翻身战（EP021—030）**：片场安全事故与抢角；吕步凭真本事拿下首个有台词角色，却得罪顾子昂。
4. **综艺围猎局（EP031—040）**：节目组利用“疯汉”人设剪辑他；吕步学会用规则和直播反制，获得大众姓名权。
5. **真正的吕布（EP041—050）**：争演新版吕布；他必须亲手演出自己最耻辱的死亡，并以作品击败顶流。
6. **封神即围城（EP051—060）**：爆红、代言、身份质疑、旧案反噬；苏晚晴的黑历史被翻出，搭档关系第一次破裂。
7. **资本白门楼（EP061—070）**：曜星用旧合同夺人；吕步拒绝高价收编，为伙伴背下违约风险，决意自立。
8. **草台班子创业（EP071—080）**：招募过气演员和技术新人，拍第一部低成本漫改项目；他从主将变成主帅。
9. **公司生死局（EP081—090）**：撤资、抄袭指控、数据造假与片场事故；团队分裂又重组，公开资本操控证据。
10. **我写我的结局（EP091—100）**：吕步拍摄《白门楼》，重演一生；作品封神、公司成立，他在同一声“斩”中选择以角色完成死亡、以吕步身份站起来。

## 7. 视觉与声音方向

- **古代段**：冷月、火光、雨水、铁锈色；斩刀声与现代场记板“咔”形成跨时空声桥。
- **现代初期**：高饱和广告屏、车流和手机提示音构成信息轰炸；吕步常被玻璃门、扫码器、自动设备“击败”。
- **成长后期**：镜头从仰视他一人，逐渐转为容纳团队的横向构图；“方天画戟”由凶器变为表演道具和公司标志。
- **标志性动作**：拒跪、抓住落刀、护住同伴、把合同压在桌上、亲手喊“开机”。
- **前期错位笑料母题（EP002—020）**：
  - **交通线（仅三条）**：摩托贴脸掠过（EP002）→ 外卖摩托（EP011）→ 轿车（EP012）；不再把电动车、地铁、共享单车、跑步机等现代物比作战马。
  - **机关妖物线**：自动门、电梯、自动售货机、扫码支付、吹风机、冲水马桶
  - **笑料结构**：先按古代经验自信误判 → 当众出丑或被物“反杀” → 苏晚晴/唐小满用现代词解释 → 吕步用古词复述（如把导航叫“指路术士”）形成二次笑点
- **声音母题**：“斩！”从死亡命令，变成场记声、舆论审判声，最终被吕步改写成“开机！”
